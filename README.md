## 🌐 Deploy on GitHub Pages

1. Fork or clone this repo
2. Go to **Settings → Pages**
3. Set source to `main` branch, `/ (root)`
4. Your site will be live at `https://inayat-dev.github.io/portfolio`

## ✏️ Customization

All content is in `index.html`. To update:

- **Contact info** → search for `bukerainayat9737` or `9737801738`
- **Project links** → find `github.com/Inayat-dev/` and update URLs
- **Colors** → edit CSS variables at the top inside `:root { ... }`
- **New project** → copy any `.project-card` div and update the content
